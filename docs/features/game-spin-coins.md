# Pogodi Pesmu, Ploča dana, Studio Coins, shop and anti-abuse

Feature reference split out of CLAUDE.md (2026-11-26). The cross-cutting rules in CLAUDE.md still apply here.

**Ploča dana, Studio Coins, shop and anti-abuse (2026-11-26):**
- **Ploča dana (daily spin, 2026-11-26)**: its own page **`/ploca`** (`client/src/pages/ploca.tsx`, public route - guests see the record + prizes + sign-up CTA; `noIndex`, Disallowed in robots.txt). Linked from the Zajednica mega menu and from the "Za tebe danas" strip (`useForYouItems`, item shown until today's spin is used). One spin per verified user **and per IP** per Belgrade day. **The server decides the reward** (`POST /api/spin` → `storage.performSpin()`, one transaction behind `pg_advisory_xact_lock`, `daily_spins` unique on `(user_id, spin_date)` and partial-unique on `(ip_address, spin_date)`); the client only animates the record (`RecordDisc` in `components/spin/spin-shared.tsx`) to one sector holding that reward - the 8 sectors are visual, not the odds. Rewards/weights in `server/spin.ts` (`BASE_WEIGHTS`, expected ≈ 8.75 SC/spin): `coins_5|10|25|50|100` (Studio Coins, see below), `extra_listen` (+1 listen today - `bonusListens`/`maxListens` on `GET /api/game/today`; only offered if today's challenge exists and the user hasn't guessed), `feature_post` (sets `posts.featured_until` = now+24h on the user's latest post; feed sorts featured first; only offered if the user has a post), `nothing` (owner kept it). An ineligible perk's weight falls to `nothing`. `studio_50` (direct 50% voucher) and `points` (+5 rank points) are **retired** - studio discounts now come only from the shop (owner decision 2026-11-26); the types/labels stay so old history rows render. Client mirrors: `SECTORS`, `PRIZES` in `components/spin/spin-shared.tsx` - change them together with `BASE_WEIGHTS`.
- **Spin IP**: `getSpinIp()` (re-export of `getTrustedClientIp()` from `server/client-ip.ts`) takes the **rightmost public** `X-Forwarded-For` hop (proxies append; the leftmost entry is client-forgeable). Don't switch it to `getClientIp()` from `routes.ts`, which uses the leftmost hop and is fine only for low-stakes stats. `spinRateLimiter` (10 / 10 min) only guards against floods.
- **Switches**: settings `spin_enabled` and `shop_enabled` (absent = on), toggled in the admin **Prodavnica** tab (shown to Super Admin only; `PUT /api/admin/spin-settings` is `requireAdmin`).
- **Admin reset on `/ploca`**: a "Reset" button under the result, rendered only for `role === "admin"`, calls `POST /api/admin/spin/reset` (`requireAdmin`) which deletes **your own** spin for today plus whatever it granted (voucher row, featured post flag) so you can test again. It also removes the coins that spin paid out.
- **More ways to earn Studio Coins (2026-11-26, amounts in `server/coins.ts`)**: every payout is a `coin_ledger` row with a `ref_id`, protected by the partial unique index `coin_ledger_ref_unique (reason, ref_id) WHERE ref_id IS NOT NULL` (replaced the old spin/game-only index) - always pass a stable `refId` for event payouts.
  - **Testimonial** +100 SC when staff approve it (`PATCH /api/admin/testimonials/:id` → `storage.awardTestimonialCoins`). The form in `MyJobsPanel` says critical-but-honest testimonials count too. **Never reward Google reviews** (Google policy) - coins are for the on-site testimonial only.
  - **Pozovi prijatelja**: `users.referral_code` (made on first `GET /api/me/referral`), table `referrals`. `?ref=CODE` on any page is kept in localStorage by `ReferralClaimer` (mounted in `App.tsx`) and claimed via `POST /api/me/referral/claim` once the new account is verified (only accounts < 72h old). `processReferrals()` (hourly job) pays both sides 100 SC after the invitee is active on 3 distinct days (spins/answers); pairs that ever shared an IP are set `blocked`; inviter payouts capped at 10/month (`capped`). UI: `InviteFriendCard` on `/prodavnica`.
  - **Weekly leaderboard**: Monday job pays last week's Pogodi Pesmu top 3 100/50/25 SC (`ref_id = leaderboardRef(weekStart, place)`); `GET /api/game/leaderboard` returns `coinRewards`.
  - **Ploča streak**: every 7th consecutive spin day pays +50 SC (`spin_streak`, ref = spin id, inside `performSpin`); `GET /api/spin/today` returns `streak`; 20:00 job pushes "Ploča dana te čeka" to people with a 2+ day streak who haven't spun (category `spin`).
- **Pogodi Pesmu archive** `/igra/arhiva` (`igra-arhiva.tsx`): past days for practice - no points, no coins, answer revealed after a guess. `GET /api/game/archive`, `/api/game/archive/:date/clip` (same server-cut 1s slice; past dates only) and `POST /api/game/archive/:date/guess`. The clip cache holds 12 slices.
- **Economy overview** at the top of admin Prodavnica (`EconomyOverview`, `GET /api/admin/shop/stats`): coins issued by source and spent this month, coins outstanding, vouchers redeemed vs issued (redeemed = real studio work), referral counts.
- **Ploča dana sound** (`components/spin/spin-sound.ts`): synthesized Web Audio, no sample files - needle drop, vinyl crackle, a tick per sector edge timed from the same `cubic-bezier(0.12, 0.7, 0.12, 1)` as the CSS spin (keep the two in sync if the easing changes), and a result sting per reward. `primeAudio()` must run inside the click handler (iOS unlocks audio only in a gesture). Mute toggle under the record, stored in localStorage `ploca_zvuk`. The record label is the black FJ logo (`@/assets/leflow-logo.png`).
- **Admin "Zaštita igara"** (`AntiAbuseTab.tsx`, `ADMIN_NAV` value `anti-abuse`, `requireRole("producer")`; also in `desktop-admin/src/shell.js`): today's Pogodi Pesmu players (listens used, answer, correct) with "Vrati slušanja" / "Poništi odgovor" (deletes today's guess + listens), today's spins, and IPs shared by several accounts in the last 30 days (masked, a hint not proof). Super Admin switches `game_ip_limit` / `spin_ip_limit` (absent = on; `PUT /api/admin/anti-abuse/settings`, `requireAdmin`). With a limit off, a repeat IP is stored as `null` so the partial unique indexes don't reject the row - keep that if you touch `submitGuess`/`performSpin`.
- **Studio Coins (SC) + shop `/prodavnica`** (2026-11-26): coins are earned only - Ploča dana coin rewards and +`GAME_CORRECT_COINS` (10) per correct Pogodi Pesmu answer - and **never sold for money** (keep it that way: buying chances with money would turn this into gambling). Ledger table `coin_ledger` (balance = SUM(amount); partial unique `(reason, ref_id)` for `spin`/`game` so an event can't pay twice). `resetSpin` and admin "Poništi odgovor" also delete the matching ledger row. Shop: `shop_items` (kind `studio_voucher` | `avatar_frame`, `price_sc`, `percent_off`/`duration_days`, `monthly_stock` site-wide per Belgrade month, `active`) seeded once with 10%/20%/50% vouchers (400/900/2500 SC, stock 10/5/2) and a 30-day avatar frame (250 SC); `shop_purchases`. `POST /api/shop/buy` = one transaction behind per-user + per-item advisory locks: active, stock, balance; studio vouchers additionally need `role === "user"`, account ≥ 7 days, and no other unused unexpired voucher. Vouchers (`vouchers.type = "shop"`, `title`, `percent_off`, `LF-XXXX-XXXX`, 60 days) show in `MyVouchersPanel` and are redeemed by staff in the admin **Prodavnica** tab (`VouchersTab.tsx` + `ShopAdmin.tsx`, ADMIN_NAV value still `vouchers`, `forceMount`): switches (Ploča / Prodavnica), catalogue editor and coin grants (`requireAdmin`; producers read-only), voucher list. Avatar frame = `users.avatar_frame_until`, rendered via `hasAvatarFrame()`/`AVATAR_FRAME_CLASS` (`lib/avatar-frame.ts`) in the feed, `/u/:username` and the dashboard header. Rules live in `/pravila#ploca-dana`. Discounts are percentages, never prices. The owner was told a chance-based prize game may need approval from the Ministry of Finance (Uprava za igre na sreću) and to check with their accountant; don't drop that caveat.

**Daily game ("Pogodi Pesmu"):**
- Schema: `daily_challenges` table — `challengeDate` (unique), `clipUrl` (Cloudinary MP3), `correctAnswers` (comma-separated variants), `clipStartSeconds`, `openHour`, `openMinute` (Belgrade time, UTC+2).
- Audio playback uses the Web `AudioContext` API in `client/src/pages/igra.tsx` — fetch the Cloudinary MP3, decode via `ctx.decodeAudioData`, play a 2s slice with `source.start(0, clipStartSeconds, 2)`. No YouTube IFrame API. The `useEffect` that loads the clip uses a `cancelled` flag to discard stale async callbacks when `clipUrl` changes.
- Open-time check uses DST-safe Belgrade time — **never** hardcode `(utcHour + 2) % 24`. Use `new Date(new Date().toLocaleString('en-US', { timeZone: 'Europe/Belgrade' }))` for hour/minute, and `new Intl.DateTimeFormat('sv', { timeZone: 'Europe/Belgrade' }).format(new Date())` for date strings. `getTodayDateString()` in `storage.ts` uses this pattern.
- Parsing hour/minute: **never** use `Number(x) || fallback` when x can be 0 — use `x != null ? parseInt(String(x), 10) : fallback`. The admin form uses `<Input type="time">` which returns `"HH:MM"`.
- Game clip upload: `POST /api/upload/game-clip` (requireAdmin) → `server/cloudinary.ts` `uploadAudioToCloudinary()`. Each upload gets a unique public_id (`basename_timestamp`) to avoid Cloudinary duplicate-key errors.
- User-facing game routes use `requireVerifiedEmail` (not `requireAuth`, which doesn't exist).
- `submitGuess()` returns `{ correct, points }` where points = correct ? 10 : 0. The correct answer is **not** exposed in the response.
- **Anti-cheat (reworked 2026-11-26):**
  - `GET /api/game/today` strips `clipUrl`/`correctAnswers`; only `hasClip` is sent.
  - **`/api/game/clip` sends only the playable snippet, never the song.** `server/game-clip.ts` `getClipSlice()` cuts `CLIP_SECONDS` (1s) from `clipStartSeconds` with ffmpeg, re-encodes to MP3 with all metadata dropped (uploaded MP3s' ID3 title = the answer) and caches one slice per challenge in memory. The client plays the whole buffer from 0 - don't reintroduce `source.start(0, clipStartSeconds, ...)`. Still capped at 6 fetches/user/day (`clipFetchCounts`, in-memory).
  - **Listens are counted server-side** in table `game_listens` (`POST /api/game/listen`, atomic conditional upsert, max = `perksFor(rank).gameListens` + 1 if today's Ploča dana gave `extra_listen`). `GET /api/game/today` returns `maxListens`/`listensLeft`. The old `igra_plays_*` localStorage counter is gone - don't bring it back.
  - **One answer per IP per day** (`daily_guesses.ip_address`, partial unique index, IP from `getTrustedClientIp()` in `server/client-ip.ts`), on top of one per account. Unique violations from parallel requests return 409/429 without revealing correctness.
  - All game routes (`today`, `clip`, `listen`, `guess`, `leaderboard`) are `requireVerifiedEmail` (were `requireNotBanned`), so throwaway unverified accounts can't play.
- `getWeekStart()` in both `routes.ts` and `storage.ts` must use Belgrade time (same as `getTodayDateString()`). Using UTC causes the wrong week bucket near Sunday/Monday midnight Belgrade time.
- **`GET /api/game/leaderboard` returns an object, not an array:** `{ weekStart: string, leaderboard: LeaderboardEntry[], prize: any }`. Always extract `data?.leaderboard ?? []` — calling `.slice()` or `.map()` directly on `data` throws `TypeError: e.slice is not a function`.
